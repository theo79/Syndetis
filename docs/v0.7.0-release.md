# Syndetis v0.7.0 release manifest

## Release

Syndetis v0.7.0 adds user-initiated PROFINET DCP discovery alongside passive LLDP/CDP. On the OLED, choose **PROFINET → Start discovery** to send one Layer 2 Identify All request on the connected segment. The tester can leave wired IPv4 off. The OLED and Wi-Fi dashboard show replying stations and their advertised properties. The browser’s JSON diagnostic report includes scan state and counters, with the station inventory available through **Include network identifiers**.

On November 27, 2026, the project owner discovered a Siemens SIMATIC S7-1200 without wired IPv4, confirmed passive LLDP and a 100 Mbps full-duplex link, used the mobile dashboard, and initiated a JSON report download. The documented scan showed zero PROFINET overflow, malformed frames, and queue drops. Discovery results depend on the responding devices and local Layer 2 forwarding. [Field acceptance](v0.7.0-field-acceptance.md)

## Installation

Use the OTA image to update an existing installation through **Settings → Firmware Update**. Verify the downloaded image against its checksum file and keep power stable during the update. Use a trusted image on a controlled local connection. For blank-device installation or recovery, follow the USB instructions.
