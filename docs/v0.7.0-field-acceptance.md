# Syndetis v0.7.0 field acceptance

On November 27, 2026, the project owner approved v0.7.0 for stable release after field testing with a Siemens SIMATIC S7-1200 PLC.

| Check | Project owner’s observation |
| --- | --- |
| PROFINET DCP discovery | Discovered the Siemens SIMATIC S7-1200 successfully. |
| Wired IPv4 | Discovery succeeded without an IPv4 address on the tester’s Ethernet interface. |
| Passive LLDP | Discovered an LLDP neighbor successfully. |
| Ethernet link | Negotiated 100 Mbps, full duplex. |
| Mobile browser dashboard | Displayed status and discovery data. |
| JSON diagnostic report | Initiated the report download successfully. |
| PROFINET scan counters | Observed zero overflow, malformed frames, and queue drops during the documented scan. |

The observations apply to the tested device and network setup. The README includes four sanitized screenshots from the session.
