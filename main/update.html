Syndetis Firmware Update

Keep the device powered. Use a Syndetis application .bin file. Your current firmware stays available if the update fails.

Open Settings → Firmware Update on the device. Local HTTP is not encrypted and firmware is not signature-authenticated.

Select an application .bin.

After verification the device reboots. Reopen its dashboard and check the firmware version. If the new firmware cannot pass its startup checks, the previous version returns.
